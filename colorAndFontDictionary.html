Rendering notes

  • NP: bars / borders / dividers blend 10 / 28 / 18% toward text; dim text 40% toward content; pressed fill 55% toward selection.
  • EQ Studio: wells darken content 40%, then slots another 40%. Meter colors are host-owned. Theme, contrast guards and user overrides can change the result.
  • The host requests studio.tree.*; our wasabi.tree.* roles fall back to list/selection colors.
  • EQ Studio does not use wasabi.window.background.
  • Gradients, antialiasing, noise, state shading, chrome tint and the 8% LCD ink blend create uncounted derived pixels.
  • Artist-supplied PNGs are not generated or counted as font/color source references; the logo glyph uses a 32px input.
